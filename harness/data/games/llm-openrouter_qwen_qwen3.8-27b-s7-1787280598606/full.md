## Post-Game Reflection

### 1. How the Game Went

I opened with a solid hand (Telework Contract, Sure Gamble, Mayfly, 2× Conduit) and kept it. The early game was very favorable: Corp left Remote 1 and HQ ice-free for my first two turns, and I capitalized by trashing Regolith Mining License and Urtica Cipher from hand/remote, then **stealing Orbital Superiority (2 AP) and Offworld Office (2 AP) from ice-free HQ** on turns 2 and 3, reaching 4/7.

From turn 4 on, Corp aggressively iced every server. By turn 7, HQ had Brân 1.0 (strength-6 barrier), R&D had Karunā (sentry), Archives and Remote 0 had multiple ice. My rig was underpowered: Leech (1 virus counter), Unity (decoder, strength 1), DZMZ Optimizer — no fracter, no killer, no Mayfly in play. I had 2 clicks of gain-per-turn economy, which was far behind Corp's Hedge Fund + Government Subsidy + Nico Campaign money engine.

The game ended on turn 8 when I ran R&D via Jailbreak with **only 1 card in my grip** (Conduit), hit rezzed Karunā (two 2-net-damage subroutines), and flatlined.

### 2. Plan and How It Changed

**Original plan (turns 1–3):** Exploit ice-free servers to steal unadvanced agendas and trash Corp assets. This worked perfectly — 4 AP in 3 turns.

**Adaptation (turns 4–6):** Corp began icing everything. I shifted to a long-term build: Leech for strength reduction, Unity for code gates, DZMZ for +1 MU and install discount. I was essentially stalling, drawing and gaining, waiting for a window.

**Late game (turns 7–8):** With no real window (every server iced), I relied on Jailbreak (0-cost run) to push through. The plan was "if the ice is a code gate Unity can handle, or the Corp can't afford to rez it, I get access." That gamble backfired twice: Brân 1.0 on HQ (unbreakable barrier), then Karunā on R&D (sentry, fatal damage).

### 3. Key Turning Points

- **Turn 3, HQ steal of Offworld Office:** Peak of the game. 4 AP with an open board.
- **Corp's turn-5 Hedge Fund / turn-7 Government Subsidy:** Corp's economy snowballed (14c → 20c → 10c after rezzing), letting them rez expensive ice and stack it.
- **Turn 7, Brân 1.0 on HQ:** The wall I couldn't get through. No fracter, no clicks for Brân's "Lose [click]: Break 1 subroutine" ability. This locked me out of my best server.
- **Turn 8, Karunā on R&D:** The fatal one. I ran with 1 card in grip into a sentry.

### 4. What I'd Do Differently

- **Never run with ≤2 cards in grip into unknown ice.** This is the biggest mistake. From turn 4 onward, I was consistently running with 1–2 cards in grip. I should have prioritized drawing to 4–5 cards before any run, even at the cost of tempo. The Corp's sentries (Karunā, Diviner, Tithe) are all 1–2 net damage; with 1 card in grip, any sentry is an automatic loss.
- **Draw more, run less, in the mid-game.** I spent too many clicks on "gain" when I was already at 2–3 credits. With DZMZ in play, I could have installed more programs. I should have been drawing 2+ cards per turn to keep my grip full.
- **Use Overclock if I'd drawn it** to fund a run with extra credits for breaking. I didn't draw it, but the principle stands: I needed more breakers (a fracter especially) before the board got fully iced.
- **Consider running Archives for free Leech/Conduit counters** more often when I had spare clicks, to build virus counters as a strength-reduction cushion.

### 5. Interface Feedback

The interface was generally excellent and well-structured:

- **Run phases were crystal clear** — Initiation → Approach → Encounter → Movement → Access → End, each as a separate decision with context.
- **Hidden ice displayed correctly** as `{"hidden": true}` until rezzed, with public info (position, counters) visible. This matched the rules accurately.
- **The "then" field on Jailbreak options** (e.g., `play Jailbreak → then run R&D`) was a great way to commit to a multi-step action in one click.
- **One minor friction:** During encounter windows, the state shows grip contents but not a prominent "grip size = N, flatline threshold = N" warning. A small reminder like "⚠️ 1 card in grip — any net damage is fatal" would have been a helpful guardrail against the exact mistake that lost this game.
- **The option list was always correctly scoped** — I never saw illegal actions, and the numbering was consistent. No confusion about what was available.

Overall, a clean, well-structured interface. The loss was a strategic one (greedy running with a thin grip into sentries), not an interface one.
